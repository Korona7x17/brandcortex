Line-glyph icons. Every icon in the system is stroke-only on `currentColor` — never filled, never coloured, never an emoji.

```jsx
<Icon name="search" size={14} strokeWidth={1.8} />
<Icon name="terminal" size={22} />
```

The set matches the source's inline paths. For glyphs outside it, use Lucide at the same stroke weight — see ICONOGRAPHY in readme.md.
