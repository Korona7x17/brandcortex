Opens every major section. Sections are numbered in sequence down the page.

```jsx
<SectionHead index="02 · Featured" title={<>Editor's <em>picks</em></>} cta="All featured →" />
<SectionHead index="03 · Index" title={<>Browse <em>everything</em></>} desc="143 entries, filterable by category and platform." />
```

Exactly one `<em>` per title — that italic serif word is the only ornament the system allows.
