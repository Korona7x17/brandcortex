Numeric summary under a hero or page head. Values are always mono; captions always uppercase.

```jsx
<StatRow items={[
  { v:'143', l:'Skills' },
  { v:'16',  l:'Categories' },
  { v:'18',  l:'Platforms' },
  { v:'100%',l:'Open source' }
]} />
```

Use `variant="inverse"` with `columns={4}` inside the black stats band on About.
