AgenticSkills · Design system

Monochrome, editorial.

Pure neutrals, hairline grids, Geist + Geist Mono with one serif italic accent per headline. Built from the redesigned directory. This page is a plain-HTML overview — everything here also appears in the Design System tab once the file type is set.

To get the Design System tab: Share menu → File type → Design System. That also compiles the component bundle, which the component cards and UI kit need in order to render.

01

Colors

Thirteen neutrals and no hue. Hierarchy comes from weight, scale and hairlines; emphasis comes from inverting to ink, never from tinting.

02

Type

Geist for structure, Geist Mono for every piece of metadata, Instrument Serif italic for exactly one accent word per headline.

03

Spacing

One container at 1280/32. Section rhythm in four steps. Hairline grids use zero gap — separation is the border.

04

Brand

Square corners, no shadows, two ambient animations, and stripe placeholders where imagery would go.

05

Components

27 primitives in six groups. Each has a props contract (.d.ts) and usage notes (.prompt.md). Live previews need the compiled bundle.
