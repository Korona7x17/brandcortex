Manifesto

An opinionated index, not a marketplace.

AgenticSkills is the curated directory for AI agent skills. We index what's actually maintained, rank it honestly, and refuse the slop. Independent, open, and not affiliated with any platform vendor.

02 · Principles

Three commitments.

P.01

Curation over completeness.

We don't index everything. We index what's maintained, useful, and original. If a skill duplicates an existing one without adding value, we don't list it.

P.02

Open standard, no lock-in.

Every skill follows the open SKILL.md spec. Skills work across Claude, Codex, Cursor, and any agent that supports the spec. No registry, no proprietary format.

P.03

Editorial, not paid placement.

Featured listings, rankings, and recommendations are editorial. We don't accept money to rank skills higher. Featured means we'd recommend it.

Story · 2025–2026

How this started.

In late 2025, we noticed every team building with Claude Code was rewriting the same five or six prompts — debugging methods, framework idioms, deployment patterns. Each one slightly different, none indexed, all rotting in private repos.

So we started a list. The list became a spec (open SKILL.md, adopted by 18+ platforms). The spec became this index. We're a small team, working with the community, and we plan to keep it that way.

Our promise: we will never become a marketplace. The directory will stay free, the rankings will stay editorial, and the spec will stay open.
