Note 01
Direction

Monochrome — editorial, document-first

A grayscale-only redesign of agenticskills.io. The current site leans on a blue/violet gradient brand, colored category pills, S-rank green, and soft glow blobs. This direction collapses every accent to a single tonal scale and lets typography, hairline rules, and grid structure carry the hierarchy — closer to a developer reference manual or trade publication than a SaaS landing page.

  • Type — Geist Sans (display + body), Geist Mono (numerals, micro-labels, code), Instrument Serif italic for one accent word per heading.
  • Palette — pure neutrals only: ink #0a0a0a, paper #fff, six grays in between. No hue.
  • Hierarchy — weight, scale, hairlines. No colored badges, no glow, no gradient logo.
  • Density — bordered grids replace floating cards. Mono numerals + uppercase micro-labels for metadata.
  • Featured / S-rank — inverted ink pills (filled black) instead of colored ones; "FEATURED" as a 1-px black box label.
  • Motion — minimal: hairline reveals, dot pulse on the live indicator, button micro-translate on hover.
