## Bugs caught in own work

- **`posts.status` was `String(16)`** — wrote correctly, read back a bare `str`, so every
  `status is PostStatus.DRAFT` in the orchestrator was silently False for a row loaded from the
  database while still passing on the object in the identity map. Approve would have 409'd on every
  draft its own request did not create. Found because a `TestClient` test happened to reload. Fixed by
  `status_column()`; regression test verified non-vacuous by reverting the column type and watching it
  fail.
- Ruff's `line-length` gate had **never passed** in this repo. Attempted an automated wrap sweep; it
  split prose greedily at column 100 and left orphaned single words ("The", "on", "an") on their own
  lines across ~40 files. Reverted the whole thing via `git checkout` plus a full rewrite of the day's
  own files, then verified `git diff --name-only` contained only intended paths. See R-2026-08-05-01.
